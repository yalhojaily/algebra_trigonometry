الرسم يقنعك بأن المتطابقة صحيحة، والإثبات يؤكد ذلك. إثبات المتطابقة يشبه الألغاز: لديك نقطة بداية (أحد الطرفين) ونقطة نهاية (الطرف الآخر)، وأدواتك المتطابقات الأساسية والجبر. لا توجد خوارزمية واحدة، لكن هناك استراتيجيات تنجح غالبًا.

## استراتيجيات <span class="en" lang="en">Strategies</span>

<Box kind="rule" title="قواعد الإثبات" en="Hints for verifying identities">
1. **اعمل على طرف واحد**، وغالبًا الأعقد، حتى يصير مثل الآخر.
2. **لا تعامل المتطابقة كمعادلة**: لا تنقل حدودًا من طرف لآخر، ولا تضرب الطرفين في شيء، ولا تربّعهما. هذا يفترض صحة ما تريد إثباته.
3. حوّل إلى $\sin$ و $\cos$ إن لم تجد طريقًا أوضح.
4. وحّد مقامات الكسور، أو افصل كسرًا بسطه مجموع إلى كسرين.
5. اضرب البسط والمقام في **المرافق** <span class="en" lang="en">(conjugate)</span> مثل $1 - \sin x$، فيظهر $1 - \sin^2 x = \cos^2 x$.
6. حلّل: العامل المشترك، والفرق بين مربعين، والعبارة التربيعية.
7. انظر إلى الطرف الآخر وأنت تعمل: هل فيه $\sec$؟ حاول إظهار $\cos$ في المقام.
</Box>

## الإثبات بالعمل على طرف واحد <span class="en" lang="en">Working with One Side</span>

<Example n="1" title="التحويل إلى جيب وجيب تمام">
أثبت أن $\cot x + 1 = \csc x(\cos x + \sin x)$.

<Solution>
نبدأ من الطرف الأيمن (فيه ضرب يمكن توزيعه): $\csc x(\cos x + \sin x) = \dfrac{1}{\sin x}(\cos x + \sin x)$

$= \dfrac{\cos x}{\sin x} + \dfrac{\sin x}{\sin x}$

$= \cot x + 1$ ✓ وهو الطرف الأيسر.
</Solution>
</Example>

<Example n="2" title="توحيد المقامات">
أثبت أن $\dfrac{1}{1 - \sin x} + \dfrac{1}{1 + \sin x} = 2\sec^2 x$.

<Solution>
الطرف الأيسر: المقام المشترك $(1 - \sin x)(1 + \sin x) = 1 - \sin^2 x$.

$= \dfrac{(1 + \sin x) + (1 - \sin x)}{1 - \sin^2 x} = \dfrac{2}{\cos^2 x}$

$= 2\sec^2 x$ ✓
</Solution>
</Example>

<Example n="3" title="الضرب في المرافق">
أثبت أن $\dfrac{\cos x}{1 + \sin x} = \dfrac{1 - \sin x}{\cos x}$.

<Solution>
الطرف الأيسر، نضرب البسط والمقام في مرافق المقام $1 - \sin x$: $\dfrac{\cos x(1 - \sin x)}{(1 + \sin x)(1 - \sin x)}$

$= \dfrac{\cos x(1 - \sin x)}{1 - \sin^2 x} = \dfrac{\cos x(1 - \sin x)}{\cos^2 x}$

$= \dfrac{1 - \sin x}{\cos x}$ ✓
</Solution>
</Example>

<Example n="4" title="التحليل">
أثبت أن $\dfrac{\sin^4 x - \cos^4 x}{\sin^2 x - \cos^2 x} = 1$.

<Solution>
البسط فرق بين مربعين: $\sin^4 x - \cos^4 x = (\sin^2 x - \cos^2 x)(\sin^2 x + \cos^2 x)$.

$\dfrac{(\sin^2 x - \cos^2 x)(\sin^2 x + \cos^2 x)}{\sin^2 x - \cos^2 x} = \sin^2 x + \cos^2 x$

$= 1$ ✓ (حيث المقام لا يساوي صفرًا).
</Solution>
</Example>

## الإثبات بالعمل على الطرفين <span class="en" lang="en">Working with Both Sides</span>

إذا كان الطرفان معقدين، حوّل كلًّا منهما **على حدة** إلى صورة ثالثة مشتركة. هذا مشروع لأن كل خطوة متطابقة: إذا كان $A = C$ و $B = C$ فإن $A = B$.

<Example n="5" title="صورة وسطى مشتركة">
أثبت أن $\dfrac{\sec x + \tan x}{\sec x - \tan x} = \dfrac{1 + 2\sin x + \sin^2 x}{\cos^2 x}$.

<Solution>
الأيسر: اضرب البسط والمقام في $\cos x$: $\dfrac{1 + \sin x}{1 - \sin x}$. ثم في $1 + \sin x$: $\dfrac{(1 + \sin x)^2}{1 - \sin^2 x} = \dfrac{(1 + \sin x)^2}{\cos^2 x}$.

الأيمن: البسط مربع كامل: $1 + 2\sin x + \sin^2 x = (1 + \sin x)^2$، فالطرف $\dfrac{(1 + \sin x)^2}{\cos^2 x}$.

الطرفان يساويان العبارة نفسها، فالمتطابقة صحيحة ✓
</Solution>
</Example>

<Box kind="mistake" title="القيمة الواحدة لا تُثبت شيئًا">
إذا تحققت المعادلة عند $x = \tfrac{\pi}{4}$ فهذا لا يعني أنها متطابقة. لكن قيمة واحدة لا تتحقق عندها **تكفي لنفيها**. مثلًا $(\sin x + \cos x)^2 = 1$ تفشل عند $x = \tfrac{\pi}{4}$: الطرف الأيسر $2$.
</Box>

## الخلاصة <span class="en" lang="en">Summary</span>

- اعمل على طرف واحد (الأعقد)، أو حوّل الطرفين إلى صورة ثالثة مشتركة.
- لا تنقل حدودًا ولا تضرب الطرفين ولا تربّعهما.
- الأدوات: التحويل إلى $\sin$ و $\cos$، وتوحيد المقامات، والمرافق، والتحليل، وفيثاغورس.
- مثال مضاد واحد ينفي المتطابقة، والإثبات يحتاج جبرًا لكل $x$.
