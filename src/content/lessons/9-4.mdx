جمع الكسور سهل: $\tfrac{2}{x - 1} + \tfrac{3}{x + 1} = \tfrac{5x - 1}{x^2 - 1}$. الاتجاه المعاكس أصعب لكنه أنفع: تفكيك الكسر المعقد إلى قطع بسيطة يجعل التكامل في التفاضل والتكامل ممكنًا، ويُستخدم في تحليل الإشارات والدوائر الكهربائية. هذا التفكيك يُختزل في النهاية إلى حل نظام معادلات خطية.

## تفكيك المقادير النسبية <span class="en" lang="en">Decomposition of Rational Expressions</span>

<Box kind="rule" title="خطوات التفكيك" en="Partial fraction decomposition of f(x)/g(x)">
1. إذا كانت درجة البسط $\ge$ درجة المقام، **اقسم** أولًا: $\tfrac{f(x)}{g(x)} = q(x) + \tfrac{r(x)}{g(x)}$، وفكّك الباقي.
2. حلّل المقام $g(x)$ إلى عوامل خطية وتربيعية غير قابلة للتحليل.
3. اكتب صورة التفكيك حسب العوامل (الجدول أدناه).
4. اضرب في المقام، وأوجد الثوابت بتعويض قيم مناسبة لـ $x$ أو بمقارنة المعاملات (نظام معادلات).
</Box>

<Box kind="def" title="صورة التفكيك حسب العوامل" en="Form of the decomposition">
| العامل في المقام | الحدود في التفكيك |
|---|---|
| خطي $(ax + b)$ | $\dfrac{A}{ax + b}$ |
| خطي مكرر $(ax + b)^m$ | $\dfrac{A_1}{ax + b} + \dfrac{A_2}{(ax + b)^2} + \cdots + \dfrac{A_m}{(ax + b)^m}$ |
| تربيعي $(ax^2 + bx + c)$ | $\dfrac{Bx + C}{ax^2 + bx + c}$ |
| تربيعي مكرر $(ax^2 + bx + c)^m$ | $\dfrac{B_1x + C_1}{ax^2 + bx + c} + \cdots + \dfrac{B_mx + C_m}{(ax^2 + bx + c)^m}$ |
</Box>

<Deep title="لماذا هذه الصور بالذات؟">
**لماذا $Bx + C$ فوق التربيعي؟** كل كسر في التفكيك يجب أن يكون بسطه أقل درجة من مقامه، وإلا أمكن قسمته أكثر. المقام الخطي يسمح ببسط ثابت $A$، والمقام التربيعي يسمح ببسط من الدرجة الأولى $Bx + C$. لو كتبنا $\tfrac{B}{x^2 + 1}$ فقط لعجزنا عن تمثيل كسر مثل $\tfrac{x}{x^2 + 1}$.

**لماذا كل القوى في العامل المكرر؟** عند جمع $\tfrac{A}{x - 1} + \tfrac{B}{(x - 1)^2} + \tfrac{C}{(x - 1)^3}$ على المقام $(x - 1)^3$ يصير البسط $A(x - 1)^2 + B(x - 1) + C$، وهو أي كثيرة حدود من الدرجة الثانية. أما $\tfrac{C}{(x - 1)^3}$ وحده فبسطه ثابت فقط.

**عدّ المجاهيل**: عدد الثوابت في التفكيك يساوي دائمًا درجة المقام. فلمقام من الدرجة 5، تحتاج 5 ثوابت، وتحصل على 5 معادلات من مقارنة معاملات $x^0$ حتى $x^4$. فالنظام مربع وله حل وحيد.

**لماذا يجوز تعويض الجذور؟** بعد الضرب في المقام تصير المعادلة متطابقة بين كثيرتي حدود، صحيحة لكل $x$، بما في ذلك الجذور التي كان المقام عندها صفرًا. وتعويض الجذر يلغي معظم الحدود فيبقى مجهول واحد.
</Deep>

## عوامل خطية مختلفة <span class="en" lang="en">Distinct Linear Factors</span>

<Example n="1" title="بداية سهلة">
فكّك $\dfrac{5x + 1}{(x - 1)(x + 2)}$.

<Solution>
$\dfrac{5x + 1}{(x - 1)(x + 2)} = \dfrac{A}{x - 1} + \dfrac{B}{x + 2}$ <span class="reason">عاملان خطيان مختلفان: ثابت لكل منهما؛ ودرجة البسط أقل فلا قسمة</span>

$5x + 1 = A(x + 2) + B(x - 1)$ <span class="reason">نضرب الطرفين في المقام المشترك</span>

عند $x = 1$: $6 = 3A$ ← $A = 2$. وعند $x = -2$: $-9 = -3B$ ← $B = 3$. <span class="reason">كل جذر يلغي أحد الحدين فيبقى مجهول واحد</span>

$= \dfrac{2}{x - 1} + \dfrac{3}{x + 2}$ <span class="reason">تحقق بالجمع: $\tfrac{2(x + 2) + 3(x - 1)}{(x - 1)(x + 2)} = \tfrac{5x + 1}{\ldots}$</span>
</Solution>
</Example>

<Example n="2" title="ثلاثة عوامل">
فكّك $\dfrac{2x^4 - 4x^3 + 6x^2 + 4x - 13}{x^3 - 4x}$.

<Solution>
درجة البسط أكبر، فنقسم: $= 2x - 4 + \dfrac{14x^2 - 12x - 13}{x(x - 2)(x + 2)}$. <span class="reason">القسمة المطولة أولًا؛ ثم نحلل $x^3 - 4x = x(x^2 - 4)$</span>

$14x^2 - 12x - 13 = A(x - 2)(x + 2) + Bx(x + 2) + Cx(x - 2)$. <span class="reason">ثلاثة عوامل خطية مختلفة، فثلاثة ثوابت؛ ثم الضرب في المقام</span>

عند $x = 0$: $-13 = -4A$ ← $A = \tfrac{13}{4}$. عند $x = 2$: $19 = 8B$ ← $B = \tfrac{19}{8}$. عند $x = -2$: $67 = 8C$ ← $C = \tfrac{67}{8}$. <span class="reason">جذور المقام الثلاثة؛ عند $x = 2$: $56 - 24 - 13 = 19$</span>

$= 2x - 4 + \dfrac{13/4}{x} + \dfrac{19/8}{x - 2} + \dfrac{67/8}{x + 2}$ <span class="reason">لا ننسى ناتج القسمة $2x - 4$</span>
</Solution>
</Example>

<Box kind="mistake" title="اقسم أولًا إذا لم يكن الكسر فعليًّا">
لو بدأت التفكيك في المثال السابق دون قسمة لما وجدت ثوابت تحقق المعادلة: الطرف الأيسر من الدرجة 4 والأيمن من الدرجة 2 على الأكثر. افحص الدرجتين دائمًا قبل كتابة صورة التفكيك.
</Box>

## عوامل خطية مكررة <span class="en" lang="en">Repeated Linear Factors</span>

<Example n="3" title="عامل مكرر">
فكّك $\dfrac{2x}{(x - 1)^3}$.

<Solution>
$\dfrac{2x}{(x - 1)^3} = \dfrac{A}{x - 1} + \dfrac{B}{(x - 1)^2} + \dfrac{C}{(x - 1)^3}$، فإن $2x = A(x - 1)^2 + B(x - 1) + C$. <span class="reason">عامل مكرر ثلاث مرات: حد لكل قوة من 1 إلى 3</span>

عند $x = 1$: $C = 2$. ومعامل $x^2$: $A = 0$. ومعامل $x$: $-2A + B = 2$ ← $B = 2$. <span class="reason">جذر واحد فقط يعطي معادلة واحدة؛ والباقي من مقارنة المعاملات</span>

$\dfrac{2x}{(x - 1)^3} = \dfrac{2}{(x - 1)^2} + \dfrac{2}{(x - 1)^3}$ <span class="reason">$A = 0$ مقبول: بعض الثوابت قد تساوي صفرًا</span>
</Solution>
</Example>

<Box kind="mistake" title="لا تنسَ القوى الأدنى">
العامل $(x - 1)^3$ يحتاج **ثلاثة** حدود: $\tfrac{A}{x - 1} + \tfrac{B}{(x - 1)^2} + \tfrac{C}{(x - 1)^3}$. كتابة الحد الأخير وحده تجعل النظام بلا حل.
</Box>

<Example n="4" title="مستوى الاختبار: قسمة ثم عامل مكرر">
فكّك $\dfrac{x^3}{x^2 - 2x + 1}$.

<Solution>
$x^3 \div (x^2 - 2x + 1) = x + 2$ والباقي $3x - 2$: $\dfrac{x^3}{(x - 1)^2} = x + 2 + \dfrac{3x - 2}{(x - 1)^2}$ <span class="reason">البسط من الدرجة 3 والمقام من الدرجة 2، فالقسمة إلزامية؛ والمقام مربع كامل</span>

$\dfrac{3x - 2}{(x - 1)^2} = \dfrac{A}{x - 1} + \dfrac{B}{(x - 1)^2}$ ← $3x - 2 = A(x - 1) + B$ <span class="reason">عامل مكرر مرتين: حدان</span>

عند $x = 1$: $B = 1$. ومعامل $x$: $A = 3$. <span class="reason">الجذر يعطي $B$، ومقارنة معامل $x$ تعطي $A$</span>

$= x + 2 + \dfrac{3}{x - 1} + \dfrac{1}{(x - 1)^2}$ <span class="reason">تحقق عند $x = 0$: الأصل $0$، والتفكيك $2 - 3 + 1 = 0$</span>
</Solution>
</Example>

## عوامل خطية وتربيعية مختلفة <span class="en" lang="en">Distinct Linear and Quadratic Factors</span>

<Example n="5" title="خطي وتربيعي">
فكّك $\dfrac{x^2 + 3x - 1}{(x + 1)(x^2 + 2)}$.

<Solution>
$\dfrac{A}{x + 1} + \dfrac{Bx + C}{x^2 + 2}$، فإن $x^2 + 3x - 1 = A(x^2 + 2) + (Bx + C)(x + 1)$. <span class="reason">$x^2 + 2$ لا يتحلل في الأعداد الحقيقية، فبسطه من الدرجة الأولى</span>

عند $x = -1$: $-3 = 3A$ ← $A = -1$. ومعامل $x^2$: $A + B = 1$ ← $B = 2$. والثابت: $2A + C = -1$ ← $C = 1$. <span class="reason">جذر واحد حقيقي، ثم معادلتان من المعاملات تكفيان للمجهولين الباقيين</span>

$= \dfrac{-1}{x + 1} + \dfrac{2x + 1}{x^2 + 2}$ <span class="reason">تحقق بمعامل $x$: $B + C = 3$ ✓</span>
</Solution>
</Example>

<Example n="6" title="عامل x مع تربيعي">
فكّك $\dfrac{3x^2 + 2x + 5}{x^3 + x}$.

<Solution>
$x^3 + x = x(x^2 + 1)$، فالصورة $\dfrac{A}{x} + \dfrac{Bx + C}{x^2 + 1}$. <span class="reason">نحلل المقام أولًا: عامل خطي وتربيعي غير قابل للتحليل</span>

$3x^2 + 2x + 5 = A(x^2 + 1) + (Bx + C)x$؛ عند $x = 0$: $A = 5$. <span class="reason">الجذر $0$ يلغي الحد الثاني</span>

معامل $x^2$: $A + B = 3$ ← $B = -2$. ومعامل $x$: $C = 2$. <span class="reason">مقارنة المعاملات بعد فك الأقواس: $(A + B)x^2 + Cx + A$</span>

$= \dfrac{5}{x} + \dfrac{-2x + 2}{x^2 + 1}$ <span class="reason">الثابت: $A = 5$ ✓ يطابق البسط</span>
</Solution>
</Example>

## عوامل تربيعية مكررة <span class="en" lang="en">Repeated Quadratic Factors</span>

<Example n="7" title="تربيعي مكرر">
فكّك $\dfrac{2x}{(x^2 + 1)^2(x - 1)}$.

<Solution>
$\dfrac{A}{x - 1} + \dfrac{Bx + C}{x^2 + 1} + \dfrac{Dx + E}{(x^2 + 1)^2}$ <span class="reason">المقام من الدرجة 5، فخمسة ثوابت</span>

$2x = A(x^2 + 1)^2 + (Bx + C)(x^2 + 1)(x - 1) + (Dx + E)(x - 1)$؛ عند $x = 1$: $2 = 4A$ ← $A = \tfrac12$. <span class="reason">الجذر الحقيقي الوحيد يعطي $A$ مباشرة</span>

مقارنة المعاملات: $x^4$: $A + B = 0$، $x^3$: $C - B = 0$، $x^2$: $2A + B - C + D = 0$، $x$: $C - B - D + E = 2$. <span class="reason">نظام خطي بالمجاهيل الباقية؛ نحله بالتعويض المتتالي</span>

$B = -\tfrac12$، $C = -\tfrac12$، $D = -1$، $E = 1$. والتفكيك: $\dfrac{1/2}{x - 1} - \dfrac{\tfrac12 x + \tfrac12}{x^2 + 1} + \dfrac{-x + 1}{(x^2 + 1)^2}$. <span class="reason">نعوّض كل قيمة في المعادلة التالية بالترتيب</span>
</Solution>
</Example>

<Box kind="note" title="أين ستستخدم هذا؟">
في التفاضل والتكامل: $\int \tfrac{5x + 1}{(x - 1)(x + 2)}\,dx$ صعب كما هو، لكن بعد التفكيك يصير تكامل $\tfrac{2}{x - 1}$ و $\tfrac{3}{x + 2}$، وكل منهما لوغاريتم. وفي الهندسة الكهربائية تُستخدم الطريقة نفسها مع تحويل لابلاس لحل معادلات الدوائر. وفي الفصل 11 تساعد على جمع متسلسلات مثل $\sum \tfrac{1}{k(k + 1)}$ لأن حدودها تختصر.
</Box>

## الخلاصة <span class="en" lang="en">Summary</span>

- اقسم أولًا إن كان البسط بدرجة المقام أو أعلى.
- عامل خطي ← $A$، مكرر ← حد لكل قوة، تربيعي ← $Bx + C$.
- عدد الثوابت يساوي درجة المقام.
- اضرب في المقام، ثم عوّض الجذور أو قارن المعاملات.
